# GG Stream Releases

Este repositório contém somente binários publicados e notices de distribuição
do GG Stream. O código-fonte proprietário fica fora deste repositório.

Os hooks/inject helpers do OBS permanecem os binários oficiais fixados em
`OBS-PIN.md`. A política de anti-cheat está em `OBS-ANTI-CHEAT.md`.

Para instalar, baixe o asset `.exe` da release mais recente e execute-o no
Windows. As atualizações posteriores são oferecidas pelo próprio aplicativo.
